## Дополнительные проверки

- `npm run sim -- --ai 8 --minutes 5 --seed 42 --speed 4 --verify` — два запуска дают идентичный финальный fingerprint.
- `npm run sim -- --ai 1 --minutes 2 --seed 7 --difficulty 1 --speed 4` — завершается без нарушения инвариантов.
- `npm run map` — 320/340 связных регионов, все пиксели суши распределены, смежность симметрична, 20 столиц.
- `npm run check` — синтаксис всех модулей, клиентский код ≈43.0 KiB gzip без карты/шрифтов.

## Сознательные отличия от неоднозначных мест brief

1. Гарнизон защитника при неудачной атаке сохраняет остаток, а не исчезает полностью.
2. Вероятность разрушения постройки использует явную формулу оставшегося HP; optional overkill-коэффициент выключен по умолчанию.
3. Победа по умолчанию 65% мира или лидерство по времени; 100% захват доступен в настройках.
4. 60 FPS на конкретном телефоне не заявляется без замера на устройстве.
